# Амфора — фронтенд (ЛР5)

Одностраничное приложение (SPA) на **React + TypeScript** для гостя: просмотр
категорий импортных находок в виде **ленты** и **плитки**.
Тема: «Оценка торговых связей по статистике импортных находок».

Бэкенд (веб-сервис на Go) — репозиторий
[web-app-development-2026](https://github.com/umidjaaan/web-app-development-2026), ветка `lab4`.

## Стек

| Что | Зачем |
|---|---|
| React 18, TypeScript | компоненты и типизация |
| Vite | сборщик и dev-сервер (порт 3000, прокси `/api` → `localhost:8080`) |
| React Router 6 | маршруты страниц |
| React-Bootstrap 2, Bootstrap 5 | готовые компоненты: `Card`, `Form`, `Button`, `Navbar`, `Nav`, `Row/Col`, `Badge`, `Spinner` |

Redux и React Context в ЛР5 не используются: состояние хранится в самих
страницах (`useState`) и передаётся вниз через **props**.

## Запуск

```shell
npm install
npm run dev
```

Приложение откроется на <http://localhost:3000>.

* **Без бэкенда** (как требует ЛР5) — запрос `/api/...` завершается ошибкой
  (видно во вкладке **Network**), и карточки берутся из mock-объектов
  `src/modules/mock.ts`. В шапке страницы — жёлтая метка «mock-данные».
* **С бэкендом** — если запущен веб-сервис на `localhost:8080`, Vite проксирует
  запросы `/api/...` к нему; метка становится зелёной «веб-сервис».

## Страницы

### 1. Лента — `/import_categories/feed`, `/import_categories/feed/:id`

Одна категория на весь экран, как в ЛР1.

| Элемент | Что делает |
|---|---|
| Видео на фоне | автопроигрывание без звука; нет видео — **видео по умолчанию** `public/DefaultVideo.mp4` |
| Фото под видео | показывается, пока видео грузится; нет фото — **изображение по умолчанию** `public/DefaultImage.jpg` |
| Счётчик `2 / 14` | позиция категории в ленте и всего категорий |
| Метка «mock-данные» / «веб-сервис» | источник данных |
| Название, период бытования, автор | данные категории |
| Описание + кнопка **«Ещё» / «Свернуть»** | описание в 2 строки, по кнопке — полностью |
| Сердце с числом | количество лайков (гостю ставить лайк нельзя) |
| Кнопка **«След.»** | переход к следующей категории ленты (`next_id`), после последней — снова первая |

Данные: `GET /api/import_categories/feed?id=<ид>` (без ид — первая категория).

### 2. Плитка — `/import_categories`

Опубликованные категории карточками в две колонки и фильтр по теме.

| Элемент | Что делает |
|---|---|
| Поле **«Дата начала — не позднее»** (`type="date"`) | дата начала бытования типа; год в календаре — год до н. э. (`0500-01-01` = 500 г. до н. э.) |
| Кнопка **«Показать»** | применяет фильтр: категории, появившиеся не позднее выбранной даты |
| «Найдено категорий: N» | сколько карточек показано |
| Кнопка **«сбросить фильтр»** | видна при включённом фильтре, очищает поле и показывает все категории |
| Карточка | фото (нет фото — изображение по умолчанию), название, число лайков, период; нажатие — переход в ленту на эту категорию |

Данные: `GET /api/import_categories?date_start=ГГГГ-ММ-ДД`.

### Нижняя навигационная панель

`Navbar` из React-Bootstrap, 4 пункта: **Лента**, **Добавление**, **Плитка**, **Вход**.
Гостю в ЛР5 доступны только «Лента» и «Плитка», «Добавление» и «Вход» неактивны
(появятся в следующих лабораторных). Активный пункт подсвечен жёлтым.

## Структура

```
public/
  DefaultImage.jpg, DefaultVideo.mp4   изображение и видео по умолчанию
  img/, video/                          фото и видео для mock-объектов
src/
  main.tsx              роутер (createBrowserRouter)
  AppLayout.tsx         каркас: страница (Outlet) + нижняя панель
  Routes.ts             адреса страниц и подписи пунктов панели
  pages/FeedPage.tsx    страница «Лента»
  pages/TilesPage.tsx   страница «Плитка»
  components/
    TabBar.tsx          нижняя панель (Navbar, Nav.Link)
    CategoryCard.tsx    карточка категории (Card)
    DateFilter.tsx      фильтр по дате начала (Form, Button)
    SourceBadge.tsx     метка источника данных (Badge)
  modules/
    api.ts              запросы к веб-сервису, при ошибке — mock
    mock.ts             mock-объекты (14 категорий, у 13 и 14 нет фото и видео)
    defaults.ts         пути к изображению и видео по умолчанию
```

## Компоненты фильтрации и props

`TilesPage` хранит состояние, `DateFilter` только отображает его и сообщает о действиях:

| Prop `DateFilter` | Тип | Назначение |
|---|---|---|
| `value` | `string` | текущее значение поля даты |
| `found` | `number` | сколько категорий найдено |
| `isFiltered` | `boolean` | применён ли фильтр (показывать «сбросить фильтр») |
| `loading` | `boolean` | идёт загрузка — кнопка «Показать» неактивна |
| `onChange(value)` | функция | ввод в поле → `setDateInput` страницы |
| `onSubmit()` | функция | «Показать» → `setDateStart(dateInput)` → новый запрос |
| `onReset()` | функция | «сбросить фильтр» → очистить поле и фильтр |

`CategoryCard` получает `title`, `imageUrl`, `period`, `likes` и `onClick`.

## Хуки

| Хук | Где | Зачем |
|---|---|---|
| `useState` | `TilesPage`, `FeedPage` | поле фильтра, применённый фильтр, список/категория, источник данных, загрузка, раскрытие описания |
| `useEffect` | `TilesPage`, `FeedPage` | загрузка данных при монтировании и при изменении фильтра или ид; при размонтировании запрос отменяется (`AbortController`) |
| `useNavigate` | `TilesPage`, `FeedPage`, `TabBar` | переходы: карточка → лента, «След.», пункты панели |
| `useParams` | `FeedPage` | ид категории из адреса `/import_categories/feed/:id` |
| `useLocation` | `TabBar` | текущий адрес для подсветки активного пункта |
